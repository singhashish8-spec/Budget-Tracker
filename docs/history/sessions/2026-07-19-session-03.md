"Couldn't open the local database" on reinstall/restore — another data-loss-
adjacent bug, distinct from the ones fixed in Session 02. `bee89c5` fixed SMS

the first appearance of the OTA delivery mechanism that the project would

paths, because Android's unzipper requires them — a detail that recurs in
later OTA-pipeline PR bodies (e.g. PR #1).
