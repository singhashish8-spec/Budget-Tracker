## What happened

Picked up exactly where Session 05 left off: the *root cause* of the
database resetting on every update. PR #17 found it — SQLCipher, keyed from
the Android Keystore, could lose its key across an update, and a plaintext
open of a stale encrypted file was being misread as "corrupted," triggering
a reset. The fix: **store the database unencrypted**, protected by the
Android app sandbox instead — a permanent architectural decision, see
`roadmap/decisions.md` and `findings.md`. The same PR stood up a cloud APK
build pipeline (`.github/workflows/build-apk.yml`, signed from GitHub
Secrets) so this fix didn't have to wait on a developer's own machine. That
pipeline immediately hit two CI failures, each its own PR: Node 20 vs. the
Capacitor CLI's Node ≥22 requirement (#18), and `gradlew` committed without
its executable bit (#19) — both fixed same-session, same-day. With the
reliability work done, the session moved into the design roadmap's "Feel"
upgrade: a frosted-glass surface as an opt-in appearance option, layered on
top of the existing UI with zero rewrites via a single CSS attribute hook
(#20) — which shipped correctly but was **invisible** on real screens
because the app's flat background gave translucent cards nothing to show
against (#21, caught from the owner's on-device screenshots), then tinted
with the user's own accent colour so the glass mood follows their colour
choice (#22). Closed with screen-transition/press-feedback/reduced-motion
support (#23).
