## What happened

Opened with a large single-commit feature batch against schema v12
(`ee871c1`, schema → **v13**): bank/UPI **notification capture** via a
`NotificationListenerService` — the only route to RCS messages, which never
reach `content://sms`; native **PDF export** through Android's
`PrintManager`; festival/wedding **event budgets** with year-over-year
comparison; **CSV import** with remembered per-bank column mapping (its own
self-contained review step, since the old AI-import review screen had been
removed in 1.1.9); a bundled **ZIP export** of CSV+HTML+JSON+every warranty
document; calendar handoff for bill reminders; clipboard capture; Material
You dynamic colour; a monochrome launcher icon; and predictive back. Verified
with a full local `assembleDebug` against the real Android SDK, not just a
web build — bumped APK versionCode 6→7 / versionName 1.3.1→1.4.

The rest of the session was a from-scratch design-system pass, done because
"the UI was hard to improve — there were no primitives: the same card, row,
and progress-bar markup was hand-typed across fourteen screen files, so
every visual change cost fourteen edits" (`7ee5837`). Built `src/components/
ui/` (Card, Screen, SectionHeader, ListRow, ProgressBar, Chip, EmptyState,
Mono, CountUp, Icon), migrated Home and Transactions onto it, restored
missing focus rings (inputs were `outline: none` with no replacement — a
real accessibility regression), and consolidated haptics to exactly two call
sites. Along the way it found and fixed three bugs that weren't the point of
the commit: a silent background SMS scan could toast and vibrate with *no
user action*, on every launch and resume; the database-error screen's only
action was a data-destroying reset, blamed on encryption removed releases
earlier, when the actual common trigger is a transient cold-start timeout;
and Home was recomputing every selector — including a six-month scan per
category row — on every render.

Next, five full visual themes (`89e8a31`) replaced the single "surface"
toggle: Paper, Carbon (true OLED black), Glass (Frosted promoted to a
first-class theme), Neo (high-contrast hard-shadow), Serene (near-invisible
borders, wide soft shadow) — composing with the existing 7 accents and
light/dark. Then emoji icons were replaced with real SVGs project-wide
(`67dd992`), because "emoji ship a different set on every Android skin... so
the app's iconography changed shape depending on the phone." A same-day
on-device bug report followed and was fixed same-day: the whole Transactions
screen was sliding sideways, clipping "Transactions" to "ransactions" — root-
caused (commit message: "it was mine") to a filter chip's `white-space:
nowrap` overflowing its container once a label got long enough, and a
scrollable container's overflow-x quietly defaulting to `auto` (`bbbf0a0`).
Closed with a substantial pass making the Frosted theme "read as iOS" —
correct blur/saturation values, real Apple label/separator alpha values, an
inset top-edge hairline, iOS corner radii and timing curves — while
deliberately keeping the blur material **opt-in per-surface** rather than on
every card, because applying it universally "is the standard way to make an
Android WebView stutter" (`44a70b5`).
