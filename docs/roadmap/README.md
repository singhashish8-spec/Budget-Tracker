# `docs/roadmap/`

The "what's true now and where this is headed" layer — as opposed to
`history/`, which is the append-only record of how it got there.

- **`decisions.md`** — the single most valuable file in this whole system to
  skim first. One row per real question/decision, append-only, status
  updated in place as things resolve.
- **`architecture.md`** — the technical reference: stack, data flow,
  invariants, gaps. Kept current, not historical — edit it in place when a
  fact changes.
- **`phases.md`** — the build plan as it's actually been described across
  PR bodies ("Phase 1," "Group B," "the Pro roadmap"), reconstructed from
  the real history rather than a single canonical document (none existed
  before this session).
